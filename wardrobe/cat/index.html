Как сделать кошачьи ушки

Вам потребуется:

  • Ободок для головы
  • Картон или плотная бумага
  • Клей
  • Краски
  • Искусственный мех

  • Шаг 1

    Из картона вырежьте два треугольника для ушек.

  • Шаг 2

    Раскрасьте края ушей красками для создания эффекта меха.

  • Шаг 3

    Приклейте ушки к ободку с помощью клея.

  • Шаг 4

    По желанию, приклейте по контуру ушек мех.
